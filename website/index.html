Study with an AI without leaving your terminal.

OpenStudy is a keyboard-first study assistant. Tell it your subject, model, reasoning level, source material, and language once. After that, a prompt is all it needs.

Install OpenStudy Read the source

Five things a session knows before you ask.

The line under the prompt is the whole configuration. Each part has one key, and OpenStudy remembers your choices between launches.

····
tabSubject

Eight subjects, each with a color. The color marks your prompt and every selection you make.

ctrl+mModel

Codex or OpenCode, through the login already on your machine. The model list comes from the provider, so it is always the one your account can use.

ctrl+rReasoning

Reasoning levels are read from the selected model. You only see the levels it supports.

ctrl+fMaterial

A document from your home directory, or one downloaded from a URL (25 MB limit) into ~/.openstudy/documents.

PDF, EPUB, Markdown, plain text, Office, OpenDocument, CSV, JSON, XML, YAML, LaTeX

ctrl+lLanguage

The language you want to study in, whatever language the material is written in.

English, Spanish, French, German, Italian, Portuguese, Arabic, Chinese, Japanese, Korean, Hindi, Dutch, Russian, Turkish

Summary mode works today.

Start a session and OpenStudy turns your material into structured study notes: headings, lists, tables, and code, rendered in the terminal and scrolled with the arrow keys.

Four more modes are in the interface and not wired up yet. ctrl+l already moves between them, so you can see where the project is going. 

    ~/.openstudy/
|-- config.json       provider choice and credentials
|-- session.json      current study preferences
|-- documents/        material downloaded from URLs
`-- <session-id>/     one directory per saved session

    Your notes stay on your disk.

    Preferences, saved sessions, and downloaded documents live in one directory in your home folder. There is no OpenStudy account and no OpenStudy server.

    Existing login
    Requests go through the Codex CLI or OpenCode you have already signed in to.
    No tools
    Provider requests run without tools. The Codex adapter also uses a read-only sandbox and never asks for approval to change files.
    Free software
    GPLv3. Read it, fork it, change it. External contributions are not being accepted yet.

    The whole interface fits in a table.

    Seven keys and three slash commands. Slash commands work in both prompts.

    Key Home screen Study session
    enter Start a session Submit the prompt
    tab Choose a subject No action
    ctrl+m Choose a model No action
    ctrl+r Choose reasoning effort No action
    ctrl+f Choose study material No action
    ctrl+l Choose a language Move to the next study mode
    ctrl+c Close a modal or exit Close a modal or exit
    /setup
    Open provider setup.
    /sessions
    Open saved sessions.
    /exit
    Close OpenStudy.

    Run it from source.

    OpenStudy is a young project at version 0.1.0. There is no packaged release yet, so installing means cloning the repository.

    1. Check what you have

      • Bun 1.3 or newer
      • npm 10 or newer
      • A terminal at least 73 columns wide and 23 rows tall
      • The Codex CLI or OpenCode

    2. Sign in to a provider

      codex login
      opencode auth login

    3. Clone and start

      git clone https://github.com/Itri-Cloud-Labs/openstudy.git
cd openstudy
bun install --frozen-lockfile
npm run dev

      The first launch opens setup. Choose a provider, fill in the session options, and if you have no prompt in mind, type Hi.
