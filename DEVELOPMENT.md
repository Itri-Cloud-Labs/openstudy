# OpenStudy Development Guide

OpenStudy is a local-first terminal study assistant built with Ink, React, and TypeScript. The source of truth is `src`; `dist` is generated by `npm run build`.

## Commands

```bash
npm run dev
npm run build
npm start
npm run reset
```

## Structure

- `src/index.tsx`: app bootstrap, loading, alternate-screen terminal handling.
- `src/components`: reusable Ink UI and screens.
- `src/components/session`: active-session mode components.
- `src/session`: session-mode request orchestration and parsing.
- `src/modals`: modal implementations and manifests.
- `src/commands`: slash commands.
- `src/providers`: provider implementations and model definitions.
- `src/utils`: local config, saved sessions, input helpers, and small utilities.

## Notes

- Keep settings local under `~/.openstudy`.
- Keep study prompts in `src/prompts`.
- Do not edit `dist` directly.
- Run `npm run build` after TypeScript changes.
